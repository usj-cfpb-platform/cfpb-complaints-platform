# Proposed cohort standard

The brief (section 6.1) asks all groups to share field names, the definition of an incremental run,
minimum quality checks and minimum measures. No common standard has been published yet, so this
is our proposal; we will align if the lecturer publishes one.

1. **Field names**: snake_case CFPB API field names (see `docs/data_dictionary.md`).
2. **Incremental run**: see `docs/data_contracts.md`, section 5.
3. **Minimum quality checks**: the six dimensions of brief section 8.5 (uniqueness, completeness,
   validity, consistency, timeliness, integrity), with thresholds committed before the final run.
4. **Minimum measures**: the list in brief section 9.1, with definitions in the analysis docs.
